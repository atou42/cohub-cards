# Cohub Cards

在 Codex 聊天里一起创作图片、视频、语音和音乐。

默认是一张简单卡片：看预览、改描述、点击生成。需要调整参数或参考素材时，点 **展开编辑** 进入右侧面板，再点 **返回聊天** 收起。你和 Agent 编辑同一份草稿。

## 已安装的用户怎么用

直接在 Codex 中说：

> 用 Cohub Cards 准备一张海岸图片的创作卡片，先不要生成。

首次使用告诉它要用哪个 Cohub 空间。然后可以：

- 在卡片里修改描述，点击“生成”。
- 继续聊天：“改成暮色，保留我刚调好的设置。”
- 点击“展开编辑”，调整参数、添加参考图片或声音。
- 说“准备一段配音”或“准备一首背景音乐”，打开对应创作卡。

只有点击生成或明确让 Agent 提交生成才会调用模型并产生费用。准备和编辑草稿不提交生成。

## 朋友如何安装

目前提供源码安装，已在 macOS 的 Codex 桌面端验证。其他系统尚未实测。

准备好：

1. 支持插件和聊天内卡片的 Codex 桌面版。
2. Node.js **24 或更新版本**、npm、Git，以及可执行的 `codex` 命令。
3. Cohub 账号、可用空间和官方 CLI：

```sh
npm install -g @neta-art/cohub-cli
cohub auth login
```

下载安装：

```sh
git clone https://github.com/atou42/cohub-plugin.git
cd cohub-plugin
bash scripts/install.sh
```

安装完成后，完全退出并重新打开 Codex，然后使用上面的示例开一张创作卡。保留克隆目录，后续更新需要它。

安装脚本会下载锁定版本的依赖、构建卡片并注册本机插件市场，不会生成作品或上传素材。每位用户使用自己的 Cohub 登录，仓库不含作者的账号、草稿或测试作品。

**不要直接把 GitHub 地址添加成插件市场。** 当前发行方式需要先构建并安装运行依赖；上面的安装脚本会完成这些步骤。

## 更新

在克隆目录中执行：

```sh
git pull --ff-only
bash scripts/install.sh
```

完成后重启 Codex。升级不会删除已有草稿。

## 范围与数据

- 图片、视频、语音和音乐使用同一套卡片。可用参数、素材用途和价格读取 Cohub 的模型声明。
- Higgs 默认音色和单条参考音频可用；多音色混合所需的权重尚未被官方 CLI 支持，卡片会明确阻止该组合。
- 草稿默认保存在 `~/.local/state/cohub-cards`。插件不另存登录凭据。
- 本地参考素材每个不超过 20 MiB。点击生成时会上传到所选 Cohub 空间的公共素材地址，供模型读取。
- 提交结果不明时不会自动重试，避免重复生成和收费。
- 应用发布由官方 Cohub CLI 执行，插件展示发布结果。复杂画板编辑继续使用 Cohub 已有的 Board。

## 开发

```sh
npm ci --ignore-scripts
npm test
npm run build
```

76 项自动检查覆盖共享草稿、冲突、错误处理、重复提交防护和卡片切换。原生 Codex 中已实测聊天卡展开、共同编辑同步与返回聊天。此前已通过真实图片、视频、语音和音乐生成测试，未逐一付费测试全部模型。
